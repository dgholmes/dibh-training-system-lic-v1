# 형성평가 대응 증적 — 촬영 목록

`docs/submission/형성평가-대응-2026-09.md`가 참조하는 스크린샷 파일 목록이다.
파일명이 문서의 이미지 경로와 정확히 일치해야 한다.

- **before/** — **v1.1.6 릴리즈 APK**를 설치한 태블릿에서 촬영
- **after/** — **v1.1.7 APK**(본 브랜치 빌드)를 설치한 태블릿에서 촬영
- **방향: 세로(Portrait)** — 실제 사용 방향이며, 화면 구성도 세로를 기준으로 한다

두 세트는 **같은 기기·같은 방향(세로)·같은 환자 데이터**로 촬영해야 비교가 성립한다.
`before`의 01~10과 `after`의 01~10은 같은 화면의 전후 쌍이며, `after`의 11~12는
v1.1.7에서 신설된 화면이라 대응하는 `before`가 없다.

## 해상도에 대한 참고

기기 패널은 2560×1600이지만, 앱이 실제로 배치에 사용하는 것은 **CSS 픽셀** 기준
해상도다. DPR 2 기준 세로 방향에서는 **약 800×1280**이며, 화면 구성(단 너비,
줄바꿈 위치)은 이 값을 기준으로 설계되었다. 브라우저로 화면을 재현할 일이 있으면
2560×1600이 아니라 **800×1280**을 사용해야 실제와 같은 배치가 나온다.

기기에서 직접 촬영하는 경우에는 이 값을 신경 쓸 필요가 없다 — 촬영된 PNG는
2560×1600 그대로 저장된다.

## 준비

1. 관리자 계정으로 로그인
2. 환자 1명 등록 (예: 홍길동 / 19900512)
3. 해당 환자에 호흡 파일 2개 업로드 후 분석 1회 실행
   - `vxp data/type_samples/TYPE_A_GEN_20260508.csv` → 일반호흡
   - `vxp data/type_samples/TYPE_A_DIBH_20260508.csv` → DIBH
4. 환자 목록에 카드가 6개 이상 되도록 환자를 추가하면 04번(검색) 촬영이 쉽다
