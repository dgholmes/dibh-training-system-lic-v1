# IA-04 인증정보 변경주기 — 동작 증적

- 대상 빌드: **DIBH-Flow 릴리즈 APK** (정식 릴리즈 키 서명, `debuggable` 아님, DEBUG 배너 없음)
- 기기: Galaxy Tab S6 에뮬레이터 (Android 16)
- 정책 값: 최대 사용 기간 **90일**, 사전 알림 **만료 14일 전부터** (`src/config/passwordPolicy.js`)

## 재현 방법 — 저장 데이터를 조작하지 않음

비밀번호의 경과 일수는 **기기 날짜를 실제로 진행시켜** 만들었습니다.
저장소의 `passwordChangedAt` 값이나 그 어떤 앱 데이터도 수정하지 않았으며,
앱이 실제 시각을 기준으로 스스로 정책을 판정한 결과를 그대로 캡처한 것입니다.

| 단계 | 기기 날짜 | 경과 | 결과 |
|---|---|---|---|
| 기준 시점 | 2026-09-07 | 0일 | 초기 비밀번호를 `NewPass1!@`로 변경 → 주기 시작 |
| 사전 알림 | 2026-11-26 | **80일** | 로그인 성공 + 잔여 10일 안내 |
| 만료 | 2026-12-11 | **95일** | 로그인 시 변경 화면 강제, 진행 불가 |

## 확인되는 사항

1. **사전 알림(알림 요구사항)** — 만료 14일 전부터 잔여 일수를 안내하며, 이 시점에는 로그인이 **차단되지 않습니다**(80일 경과 시 정상 진입).
2. **주기 도래 시 강제 변경** — 90일 초과 시 비밀번호 변경 화면이 강제 표시되고, 변경 전에는 다음 화면으로 진행할 수 없습니다.
3. **사유 구분 표시** — 초기 비밀번호로 인한 변경 요구(`초기 비밀번호 변경 필요`)와 주기 도래로 인한 변경 요구(`비밀번호 변경 주기 도래`)가 서로 다른 문구로 구분되어 표시됩니다. 초기 비밀번호 화면은 `../SI-07-real-conditions/R05_초기비밀번호_변경요구.png` 참조.
4. 경과 일수(95일)와 정책 값(90일)이 화면에 함께 표시되어, 사용자가 사유를 즉시 확인할 수 있습니다.
