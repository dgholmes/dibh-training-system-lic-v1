# SI-07 오류 메시지 — 실제 발생 조건 재현 증적

- 대상 빌드: **DIBH-Flow v1.1.6 릴리즈 APK** (정식 릴리즈 키 서명, `debuggable` 아님)

- 방식: **실제 조건을 유발하여** 발생한 화면을 그대로 캡처 (디버그 하네스 미사용, DEBUG 배너 없음)

## 부수적으로 확인된 사항

- R01·R02의 잔여 시도 횟수 문구는 **실행 시점에 동적으로 조합**되는 메시지로, 소스 문자열
  추출만으로는 목록화되지 않습니다. 실제 조건 재현을 통해서만 확인되는 항목입니다.
- R03 → R04 순서는 계정 잠금이 **정상 비밀번호에 대해서도 유지**됨을 보여줍니다(IA-02).
- 모든 캡처는 릴리즈 빌드에서 취득되었으므로 DEBUG 배너가 없으며, 하단에 버전(v1.1.6)과
  유통표준코드(GTIN-13)가 함께 표시됩니다.

## 잔여 재현 대상

아래 항목은 동일한 방식으로 재현 가능하며 순차 진행 예정입니다.

| 조건 | 대상 메시지 |
|---|---|
| 중복 아이디로 계정 생성 | 이미 존재하는 아이디입니다. |
| 마지막 관리자 계정 삭제 시도 | 마지막 계정은 삭제할 수 없습니다. |
| 지원하지 않는 확장자 업로드(.txt) | CSV 또는 VXP만 업로드할 수 있습니다 |
| 환자당 11번째 파일 업로드 | 일반호흡/DIBH 데이터는 최대 10개까지 저장됩니다 |
| 손상된 백업 파일 복구 시도 | 백업 파일의 무결성 검증에 실패했습니다… |
| 변조 APK 실행 (SI-04 시험과 공유) | 무결성 검사 실패 |
| 봉인 키 손상 후 실행 | 암호화 키 오류 |

시작 자가진단 실패(Web Crypto / sessionStorage / localStorage 사용 불가)는 브라우저 API를
앱 로드 이전에 비활성화해야 하므로 실제 조건 재현이 불가능하며,
`../SI-07-error-messages/` 의 UI 렌더링 캡처로 대체합니다.
