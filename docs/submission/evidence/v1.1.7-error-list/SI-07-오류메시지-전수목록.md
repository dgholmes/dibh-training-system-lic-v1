# SI-07 — 사용자에게 표시되는 오류·경고 메시지 전수 목록

- 대상: DIBH-Flow **v1.1.7** (`com.thepict.dibhtraining`, versionCode 10107)
- 작성일: 2026-09-09
- 직전 개정: v1.1.6 기준 79건 (2026-09-08)
- 기준: **실제로 사용자 화면에 표시되는** 오류·경고 메시지

## 조사 방법

1. 소스 전체를 **구문 분석기(Babel AST)** 로 파싱하여 모든 한글 문자열 리터럴 640건을 추출했습니다.
   (정규식 검색은 `'DIBH' 가능 상태` 처럼 문장 안에 작은따옴표가 있으면 문자열 경계를 잘못 잡습니다.)
2. 각 문자열을 **표시 경로 기준으로 수작업 확인**했습니다. 자동 분류만으로는 다음을 판별할 수 없습니다.
   - 던져진 오류가 화면에 그대로 표시되는지, 아니면 상위에서 다른 문구로 대체되는지
   - 지역 상수·삼항 연산자·JSX 안에 있는 메시지
3. v1.1.6 목록(79건)을 기준선으로 두고, v1.1.7에서 **추가·삭제된 문구만 소스 diff로 확인**한 뒤
   각각을 표시 경로까지 되짚어 반영했습니다. 기존 항목의 번호는 유지했습니다.
