# SI-07 — 사용자에게 표시되는 오류·경고 메시지 전수 목록

- 대상: DIBH-Flow v1.1.6 (`com.thepict.dibhtraining`)
- 작성일: 2026-09-08
- 기준: **실제로 사용자 화면에 표시되는** 오류·경고 메시지

## 조사 방법

1. 소스 전체를 **구문 분석기(Babel AST)** 로 파싱하여 모든 한글 문자열 리터럴 613건을 추출했습니다.
   (정규식 검색은 `'DIBH' 가능 상태` 처럼 문장 안에 작은따옴표가 있으면 문자열 경계를 잘못 잡습니다.)
2. 각 문자열을 **표시 경로 기준으로 수작업 확인**했습니다. 자동 분류만으로는 다음을 판별할 수 없습니다.
   - 던져진 오류가 화면에 그대로 표시되는지, 아니면 상위에서 다른 문구로 대체되는지
   - 지역 상수·삼항 연산자·JSX 안에 있는 메시지
3. 아래 두 가지는 **집계에서 제외**했습니다. 제외 사유를 각각 명시했습니다.

## 집계 결과

| 구분 | 수량 |
|---|---|
| **사용자에게 표시되는 오류·경고 메시지 (고유 문구)** | **79** |
| 참고: 소스상 출현 위치 (동일 문구가 여러 곳에 있는 경우 각각 계수) | 85 |

아래 1~79번 목록이 전수이며, **번호와 문구가 1:1로 대응**합니다(중복 문구 없음).
동일 문구가 여러 화면·여러 위치에서 쓰이는 경우는 한 항목으로 묶고 소스 위치를 함께 표기했습니다
(예: #33 `사용자를 찾을 수 없습니다.` 4개소).

> 2026-07-16 회신의 **"약 78개"** 는 정확한 수치였습니다. 현재는 IA-04(비밀번호 변경주기) 관련
> 메시지가 추가되고, 화면에 표시되지 않는 내부 오류 1건이 제외되어 **79건**입니다.
