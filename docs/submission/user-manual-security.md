# DIBH 훈련 시스템 — 보안 사용자 설명서
## Security User Manual

**제품명:** DIBH 훈련 시스템 (DIBH-Flow) v1.1.7  
**대상:** 시스템 관리자 및 임상의  
**최종 수정:** 2026-09-08

---

## 1. 시스템 사용 전 주의사항

본 시스템은 **인가된 의료진 및 관리자만 사용**할 수 있습니다.

- 시스템에 접속하고 수행되는 **모든 활동은 기록**됩니다.
- **인가되지 않은 접근 및 사용은 금지**되며, 관련 법령에 따라 처벌받을 수 있습니다.
- 공용 또는 공공 기기에서는 사용을 금지합니다.
- 사용 종료 후 반드시 **로그아웃**하십시오.

---

## 2. 계정 및 비밀번호 관리

### 2.1 초기 로그인

신규 설치 시 기본 관리자 계정이 자동 생성됩니다.

| 항목 | 값 |
|---|---|
| 아이디 | `admin` |
| 초기 비밀번호 | `Admin@1234!` |

> ⚠ **첫 로그인 시 비밀번호를 반드시 변경하십시오.** 변경하지 않으면 시스템을 사용할 수 없습니다.

### 2.2 비밀번호 설정 규칙

비밀번호는 다음 조건을 모두 만족해야 합니다:

- 최소 **8자 이상**
- **대문자** (A-Z) 1개 이상
- **소문자** (a-z) 1개 이상
- **숫자** (0-9) 1개 이상
- **특수문자** (!@#$% 등) 1개 이상

**나쁜 예:** `password123`, `Admin1234`  
**좋은 예:** `Secure@2026!`, `Dibh#Training1`

### 2.3 비밀번호 주기적 변경

보안을 위해 **90일마다 비밀번호를 변경**하도록 권고합니다. 변경 방법:

1. 관리자 메뉴 → 계정 관리 → 해당 계정 선택
2. 새 계정을 생성하거나 담당자가 비밀번호를 재설정

### 2.4 비밀번호 보안 주의사항

- 비밀번호를 **메모지나 모니터에 부착하지 마십시오.**
- 동일한 비밀번호를 **다른 시스템과 공유하지 마십시오.**
- 비밀번호를 **타인에게 알려주지 마십시오.** (관리자 포함)

## 3. 계정 잠금 정책

로그인 **5회 연속 실패** 시 계정이 **15분간 자동 잠금**됩니다.

- 잠금 중에는 올바른 비밀번호를 입력해도 접속할 수 없습니다.
- 15분 후 자동 해제되거나, 관리자가 즉시 해제할 수 있습니다.

**관리자 잠금 해제 방법:**
1. 관리자 계정으로 로그인
2. 홈 화면 → 관리자 버튼 → 계정 관리
3. 잠금된 계정 옆 **[잠금해제]** 버튼 클릭

---

## 4. 자동 로그아웃

**30분간 활동이 없으면** 시스템이 자동으로 로그아웃됩니다.

- 로그아웃 **2분 전** 화면 하단에 경고 배너가 표시됩니다.
- 배너의 **[계속 사용]** 버튼을 클릭하면 세션이 연장됩니다.
- 자동 로그아웃 후 모든 미저장 작업은 보존되지 않습니다.

---

## 5. 역할 및 권한

시스템에는 두 가지 사용자 역할이 있습니다:

| 역할 | 권한 |
|---|---|
| **관리자 (admin)** | 모든 기능 + 계정 관리 + 감사 로그 + 백업/복구 |
| **임상의 (clinician)** | 환자 관리, 데이터 업로드, 호흡 분석, 보고서 조회 |

- 임상의는 관리자 전용 메뉴(/admin/*)에 접근할 수 없습니다.
- 최소 1개의 관리자 계정이 항상 유지되어야 합니다.

## 6. 환자 데이터 보안

### 6.1 암호화

환자 개인정보(이름, 생년월일, 담당의사)는 **AES-256-GCM 알고리즘**으로 암호화되어 저장됩니다. 데이터베이스를 직접 열람하더라도 개인정보를 확인할 수 없습니다.

### 6.2 암호화 키 관리

- 암호화 키는 **기기별로 고유**하게 생성됩니다.
- 키는 브라우저 로컬 스토리지에 보관됩니다.
- **브라우저 데이터를 초기화하면 키가 삭제**되어 기존 데이터를 복호화할 수 없게 됩니다.
- 데이터 이전이 필요한 경우 **반드시 백업 후 이전**하십시오.

> ⚠ **경고:** 브라우저 캐시/데이터 삭제 전 반드시 백업을 생성하십시오.

### 6.3 데이터 접근 제한

- 환자 데이터에는 **로그인한 사용자만 접근** 가능합니다.
- 모든 데이터 접근 및 수정은 **감사 로그에 기록**됩니다.

## 7. 파일 업로드 보안

호흡 데이터 파일(CSV, VXP) 업로드 시 다음이 자동으로 수행됩니다:

1. **파일 형식 검증** — CSV, VXP 파일만 허용
2. **SHA-256 무결성 해시** 저장 — 파일이 저장된 이후 변조 여부를 분석 시 자동 검증
3. 파일 크기 및 개수 제한 — 환자당 카테고리별 최대 10개
4. **일반호흡/DIBH 구분 확인** — 아래 7.1 참조 (v1.1.7 신설)

무결성 검증 실패 시 분석이 중단되고 경고 메시지가 표시됩니다.

### 7.1 일반호흡 / DIBH 구분 확인 (v1.1.7)

> **주의.** 호흡 데이터를 반대 구분으로 등록하면 **분석 결과(Type)가 달라집니다.**
> 파일을 올린 뒤 반드시 확인 화면의 내용을 검토한 후 등록하십시오.

`호흡 데이터 추가` 화면은 일반호흡(GEN)과 DIBH 호흡(DIBH)을 **별도 영역**으로
표시합니다. 각 영역은 고유한 색상과 구분 배지를 가지며, 파일을 올리면 다음이
수행됩니다.

1. **파일명 자동 판별** — 파일명에 포함된 구분 표기(`GEN`, `NORMAL`, `DIBH` 등)를
   읽어 해당 파일이 어느 구분인지 추정합니다. 파일명으로 판단할 수 없는 경우에는
   추정하지 않으며, 이때는 경고도 표시되지 않습니다.
2. **불일치 경고** — 파일명이 가리키는 구분과 실제로 올린 영역이 다르면, 확인
   화면에서 해당 파일이 **적색으로 강조**되고 경고 문구가 표시됩니다.
3. **등록 전 확인** — 올린 파일과 각각의 저장 대상 구분이 목록으로 표시됩니다.
   **[등록]을 누르기 전까지 파일은 저장되지 않습니다.** 잘못 지정한 경우
   [취소]를 눌러 되돌린 뒤 올바른 영역에 다시 올리십시오.

불일치 경고가 표시된 상태에서도 등록은 가능합니다(버튼 문구가 **[그대로 등록]**
으로 바뀝니다). 이는 파일명이 병원 내부 규칙과 다른 경우를 위한 것이므로,
**반드시 실제 측정 조건을 확인한 뒤에만** 진행하십시오.

### 7.2 파일 목록 표시 이름

파일 목록에는 `환자이름_GEN_20260508.csv` 형식으로 표시되지만, 기기에 저장되는
실제 파일명은 `PT-2026-001_GEN_20260508.csv`와 같이 **환자 코드** 기준입니다.
환자 이름은 암호화된 환자 정보에서 화면 표시 시점에만 조합되며, 파일명이나
분석 기록에 평문으로 저장되지 않습니다(6.1 참조).

## 8. 감사 로그

시스템의 모든 주요 활동은 자동으로 기록됩니다:

| 기록되는 활동 |
|---|
| 로그인 / 로그아웃 |
| 로그인 실패 / 계정 잠금 |
| 환자 등록 / 수정 / 삭제 |
| 파일 업로드 / 삭제 |
| 호흡 분석 실행 |
| 계정 생성 / 삭제 / 역할 변경 |
| 백업 생성 / 복구 |

**감사 로그 조회 방법:**
1. 관리자 계정으로 로그인
2. 홈 화면 → 관리자 버튼 → 감사 로그 탭
3. 날짜, 사용자명, 액션으로 검색 가능

감사 로그는 **읽기 전용**이며 UI를 통해 수정 또는 삭제할 수 없습니다.

## 9. 백업 및 복구

### 9.1 백업 생성

데이터 손실에 대비하여 정기적으로 백업을 생성하십시오.

1. 관리자 계정으로 로그인
2. 홈 → 관리자 → 백업/복구 탭
3. **[백업 파일 생성]** 클릭
4. `.enc` 파일이 자동 다운로드됨

**백업 주기 권고:** 주 1회 이상 (신규 환자 등록 또는 분석 후)

> ⚠ 백업 파일은 현재 기기의 암호화 키로 보호됩니다. **동일한 기기에서만 복구 가능**합니다. 기기 이전 시에는 기기 변경 전 백업 → 신규 기기 설치 후 복구 순으로 진행하십시오.

### 9.2 백업 보관

- 백업 파일은 **안전한 별도 저장 장치** (외장 드라이브, 병원 네트워크 스토리지)에 보관하십시오.
- 동일 기기에만 보관하지 마십시오.

### 9.3 복구

1. 관리자 → 백업/복구 탭
2. **[백업 파일 선택]** 클릭 → `.enc` 파일 선택
3. 무결성 검증 후 복구 완료 메시지 확인
4. 페이지 새로고침

> ⚠ 복구 시 현재 데이터가 백업 시점으로 **덮어씌워**집니다. 복구 전 현재 상태의 백업을 먼저 생성하십시오.

## 10. 비식별화 데이터 내보내기

연구 또는 외부 기관 제출 목적으로 데이터를 공유해야 하는 경우:

1. 관리자 → 백업/복구 탭
2. **[비식별 CSV 내보내기]** 클릭
3. 이름, 생년월일이 제외된 CSV 파일이 다운로드됨 (환자코드, 성별, 분석결과만 포함)

## 11. 사이버보안 위협 대응

### 11.1 의심스러운 활동 발견 시

다음과 같은 상황 발견 시 즉시 시스템 관리자에게 보고하십시오:

- 본인이 수행하지 않은 활동이 감사 로그에 기록됨
- 환자 데이터가 무단으로 수정되었음
- 알 수 없는 계정이 생성됨
- 비밀번호 없이 시스템에 접근 가능한 상태

### 11.2 계정 도용 의심 시

1. 즉시 비밀번호 변경 (관리자에게 요청)
2. 감사 로그에서 해당 계정의 최근 활동 확인
3. 필요 시 계정 삭제 후 신규 계정 생성

### 11.3 제조사 연락처

사이버보안 관련 인시던트 또는 취약성 발견 시:

**제품명:** DIBH Training System v1.0.0  
**문의:** 유지보수 계약에 따른 담당 채널을 통해 접수

## 13. 버전 정보 확인

현재 설치된 시스템 버전은 **로그인 화면 하단**에서 확인할 수 있습니다.

업데이트 배포 시 제조사로부터 새 버전 패키지와 함께 **SHA-256 해시값**이 제공됩니다. 설치 전 해시를 반드시 검증하십시오:

```powershell
# Windows PowerShell에서 해시 확인
Get-FileHash .\dibh-training-system-setup.exe -Algorithm SHA256
```

제공된 해시값과 일치하는 경우에만 설치를 진행하십시오.
