# 2. 모양 및 구조 (Shape and Structure)

**문서 버전:** 1.0  
**제품명:** DIBH 호흡훈련 시스템 (Software as a Medical Device, SaMD)  
**작성 목적:** 인증·허가 제출용 제품 모양 및 구조 기술 문서

---

## 1. 제품 개요

본 제품은 **심호흡 유지(DIBH, Deep Inspiration Breath Hold)** 기법 훈련을 지원하는 의료용 소프트웨어로, 호흡 벨트(센서)로 수집한 신호를 분석하여 환자의 호흡 안정성(CV) 및 DIBH 유지 능력을 평가하고, 그 결과에 따라 훈련 유형(Type A/B/C)을 결정합니다.  
시스템은 **로그인 → 환자 선택 → 장비 확인 → 캘리브레이션(3단계) → 훈련 유형 결정 → 훈련 모니터링 → 결과/보고서**의 순차 흐름으로 운영되며, 폐쇄망 또는 제한된 병원 내 네트워크 환경에서 단일 설치본(클라이언트)으로 동작하도록 설계됩니다.

---

## 2. 작용원리 (Operating Principle)

### 2.1 목적

본 소프트웨어의 핵심 작용은 다음 두 가지입니다.

1. **캘리브레이션 알고리즘:** Vernier GoDirect 호흡 벨트로부터 수집한 힘(Force, N) 시계열을 3단계로 분석하여 **호흡 변이계수(CV)** 및 **평균 DIBH 유지 시간(avgDIBH)**을 산출합니다.
2. **훈련 유형 분류:** 위 결과에 따라 **Type A(우수) / Type B(보통) / Type C(주의)**를 결정하고, 이에 맞는 훈련 모드를 제공합니다.

### 2.2 핵심 알고리즘 개요

| 단계 | 명칭 | 설명 | 출력 |
|------|------|------|------|
| 1단계 | 평상시 호흡 측정 | IIR 저역통과 필터·미분·피크/골 검출로 호흡 사이클( trough–peak–trough ) 인식, OK 사이클 10회 수집 | CV(진폭 변이계수), CV_period(주기 변이계수) |
| 2단계 | 심호흡 측정 | One-pole LPF·미분 기반으로 3회 “심호흡” 시도 검출( baseline → inhale → peak → return ) | max_amp, avg_amp, min_amp (진폭 N) |
| 3단계 | DIBH 유지 측정 | 2단계 avg_amp를 기준으로 hold_th/release_th 설정, 3회 “유지” 시도에서 유지 시간 측정( release_ratio=0.5, exhale 검출로 종료 ) | avgDIBH(초), hold_quality_pct, attempts 상세 |

**훈련 유형 결정 규칙 (determineDibhType):**

- **Type A:** avgDIBH ≥ 15초 **및** CV < 15%
- **Type C:** avgDIBH < 10초 **또는** CV ≥ 30% (단, Type A 조건 미충족 시)
- **Type B:** 그 외

## 3. 구조 및 정보통신체계도 (Structure and Network Diagram)

### 3.1 시스템 구성

본 제품은 **단일 사용자·단일 설치** 환경을 전제로 하며, 외부 서버 의존 없이 로컬(또는 병원 내 제한망)에서 동작합니다.

| 구분 | 구성요소 | 설명 |
|------|----------|------|
| 클라이언트 애플리케이션 | React 기반 SPA (Vite) | 로그인, 환자·캘리브레이션·훈련 세션 관리, 실시간 차트 및 결과 표시 |

| 외부 장비 | Vernier GoDirect 호흡 벨트 | Web Bluetooth API를 통한 BLE 연결, 힘(Force) 센서 값 수집 |
| 출력 | 화면 표시, 인쇄(훈련 보고서) | 훈련 유형, DIBH 유지 시간, CV, 세션별 결과; 필요 시 USB 등 폐쇄 매체로 데이터 반출(정책에 따름) |

## 5. 보호 조치 (Security Measures)

본 절은 **의료 소프트웨어 보안 모범 사례**를 반영한 권장 사항을 기술합니다. 실제 구현 시 인증·규정 요구사항에 맞게 반영하시기 바랍니다.

### 5.1 사용자 식별 및 접근 제어

| 조치 | 내용 |
|------|------|
| 사용자 인증 | 로그인 화면에서 아이디·비밀번호 입력; **비밀번호는 저장 시 해시(SHA-256 이상) 처리**, 전송 시 TLS 적용 권장. |
| 세션 관리 | 로그인 성공 후 **세션 토큰(또는 세션 ID)** 발급; 유휴 시간 경과 시 **자동 로그아웃(예: 30분)** 적용 권장. |
| 접근 제어 | 역할 기반 접근 제어(RBAC) 도입 시, “캘리브레이션 실행”, “환자 데이터 조회”, “보고서 인쇄” 등 기능별 권한 정의 권장. |
| 로그아웃 | 로그아웃 시 세션 무효화 및 클라이언트 내 세션 정보 삭제. |

|------|------|

| 소프트웨어 무결성 | 배포 패키지(설치본)에 **디지털 서명** 적용하여 변조 여부 검증 권장. |
| 알고리즘 상수 | 캘리브레이션 파라미터(필터 차단주파수, 비율 등) 변경 시 버전 관리 및 검증 절차 적용. |
